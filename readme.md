# 🖥️ Mini Sistema

Este projeto é um mini sistema desenvolvido como parte dos estudos de **Desenvolvimento de Sistemas**. O objetivo é praticar conceitos de programação, criação de páginas web e organização de um projeto utilizando as tecnologias estudadas em aula.

## 📌 Sobre o projeto

O **Mini Sistema** foi criado para colocar em prática conhecimentos de desenvolvimento web, trabalhando com a estrutura de páginas, formulários, lógica de programação e interação com o usuário.

O projeto ainda pode receber novas funcionalidades e melhorias conforme os estudos forem avançando.

## 🛠️ Tecnologias utilizadas

* HTML
* CSS
* PHP
* Git
* GitHub

## 📂 Estrutura do projeto

A estrutura do projeto contém os arquivos necessários para o funcionamento do sistema, incluindo páginas HTML, estilos CSS e códigos PHP.

```text
mini-sistema/
│
├── index.html
├── *.php
├── *.css
└── README.md
```

> A estrutura pode mudar conforme novas funcionalidades forem adicionadas ao projeto.

## ▶️ Como executar

Para executar o projeto localmente:

1. Baixe ou clone este repositório.
2. Coloque a pasta do projeto no servidor local, como o **XAMPP**.
3. Inicie o servidor **Apache**.
4. Abra o navegador.
5. Acesse:

```text
http://localhost/mini-sistema/
```
